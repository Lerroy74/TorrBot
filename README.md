# torrbot — фильмы на ТВ через Telegram

Пишешь боту название фильма → он ищет раздачи на rutracker, rutor, kinozal и др. (через jac.red),
отсеивает то, что приставка не потянет (4K, HEVC, HDR, remux, слишком большие) →
ты жмёшь кнопку → фильм качается на сервер → бот пишет «Скачано» → смотришь в Kodi.

```
Telegram → бот → jac.red (поиск)
               → Transmission → диск на сервере → SMB → Kodi на ТВ
```

Всё запускается в Docker двумя контейнерами: бот и торрент-клиент Transmission.

---

## 1. Диск

Нужен диск от 256 ГБ, подключённый к серверу.

```bash
lsblk -f                                  # найди диск, например sdb1, и его FSTYPE
```

**Если диск пустой или его не жалко** — отформатировать (⚠ ВСЁ НА НЁМ СОТРЁТСЯ):
```bash
sudo mkfs.ext4 -L media /dev/sdb1
```

Смонтировать навсегда:
```bash
sudo mkdir -p /mnt/media
echo "LABEL=media /mnt/media ext4 defaults,nofail 0 2" | sudo tee -a /etc/fstab
sudo mount -a && df -h /mnt/media
sudo chown -R $(id -u):$(id -g) /mnt/media
```
(если диск не форматировал, вместо `LABEL=media` поставь `UUID=...` из `lsblk -f` и его FSTYPE)

## 2. Docker

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER      # потом перелогиниться
```

## 3. Бот в Telegram

1. В @BotFather: `/newbot` → имя → получишь **токен**.
2. В @userinfobot узнай свой **ID**.

## 4. Запуск

```bash
cd ~/torrbot
cp .env.example .env
nano .env        # BOT_TOKEN, ADMIN_IDS, MEDIA_DIR, TRANSMISSION_PASS, PUID/PGID (команда id)
docker compose up -d --build
docker compose logs -f bot       # Ctrl+C — выход из логов
```

Напиши боту `/start` и название фильма.

Веб-интерфейс Transmission: `http://<адрес сервера>:9091`.

Transmission работает в сети хоста (`network_mode: host`): если на сервере стоит прозрачный прокси
(xray/TPROXY) для транзитного трафика, торренты всё равно идут напрямую через роутер.
Для скорости пробросьте на роутере порт `51413` TCP/UDP на сервер.

## Обложки (TMDB, по желанию)

Если в `.env` задан `TMDB_API_KEY`, бот над списком раздач показывает обложку, год, рейтинг и
описание фильма, а уведомления «Поставил на закачку» и «Скачано» приходят с обложкой.
Ключ бесплатный: зарегистрироваться на themoviedb.org → Настройки → API. Подходит и «API Key»,
и «API Read Access Token». Если api.themoviedb.org заблокирован — укажите `TMDB_PROXY`.
Без ключа бот работает как раньше, просто без картинок.

## Kodi: обновление медиатеки и автоочистка (по желанию)

В Kodi: **Настройки → Службы → Управление → «Разрешить удалённое управление по HTTP»**,
порт 8080, пользователь `kodi`, свой пароль. В `.env` — `KODI_URL`, `KODI_USER`, `KODI_PASS`.

- Как только фильм докачался, бот сам запускает обновление медиатеки Kodi и показывает на ТВ
  сообщение «Скачан фильм». Малинка выключена — бот повторяет раз в `KODI_RETRY_MIN` минут,
  пока не получится (и обновляет медиатеку при каждом своём запуске).
- Если раздача точно совпала с фильмом из TMDB, она кладётся в папку
  `movies/Название (год)/` или `series/Название (год)/` — так Kodi не ошибается с названием,
  а для сериалов это обязательно.
- Автоочистка (`CLEANUP_DAYS=14`): когда всё в закачке просмотрено в Kodi и с последнего
  просмотра прошло 14 дней, админ получает «через 24 ч удалю …» с кнопкой «📌 Оставить».
  Не нажал — торрент удаляется вместе с файлами, медиатека Kodi чистится.
  Недосмотренное, чего нет в медиатеке, и то, что не качал бот, не трогается никогда.
  Kodi выключен — очистка просто откладывается.
- `/cleanup` (только админ) — что просмотрено и когда будет удалено.

## Поиск

- **Название** (год не нужен): бот сначала показывает варианты из TMDB кнопками —
  «🎬 Маска (1994)», «📺 Маска (2020)», «🎬 Маска 2 (2005)». После выбора ищет раздачи по
  русскому и оригинальному названию и оставляет только раздачи именно этого фильма
  (название + год ±1, фильм/сериал). Если точных нет — показывает всё похожее с пометкой.
  Один вариант — сразу раздачи. TMDB не знает — ищет как раньше, текстом.
  У каждого варианта — 2–3 главных актёра (👥), чтобы различать одноимённые фильмы;
  если подписи кнопок совпадают, к кнопке добавляется фамилия первого актёра.
- **Актёр или режиссёр** — «Джим Керри»: самые известные фильмы кнопками
  (для режиссёров — снятые им). Ток-шоу и появления «в роли себя» не показываются.
- Кнопка «🔎 Искать как есть» — старый режим, если нужного варианта нет.

- **По описанию сюжета** — `/plot мужик находит маску и становится зелёным`, или просто
  длинный запрос. Сначала спрашивается ИИ — по очереди `AI_ORDER`: Алиса (Yandex Cloud),
  Groq, Gemini (у кого есть ключ); он понимает смысл и разговорные описания, варианты
  проверяются в TMDB. Кончился лимит у одного — берётся следующий; не ответил никто — бот
  говорит об этом и ищет по сюжетам статей Википедии (там нужны конкретные слова).
- **/podbor** — подбор кнопками: фильмы/сериалы → жанр → годы → страна → лучшие/популярные.

## v7: пульт, подписки, детский режим, место, нагрузка

- **/tv — пульт**: что играет, ⏯ ⏹, перемотка, серии, громкость, «📼 Что включить».
  Кнопки «▶ Включить на ТВ» — в «✅ Скачано» и в карточке /delete. Доступ даёт админ в /users (⚙ → 📺).
- **/podpiski** — подписки на сериалы и «⏳ жду хорошую раздачу». Подписка: кнопка
  «🔔 Следить за новыми сериями» под обложкой сериала и в сообщениях о закачке; новые серии
  качаются сами раз в `SUBS_CHECK_HOURS`, всем подписчикам приходит «Скачано».
- **🧸 Детский режим** — в /users (⚙ → 🧸): только мультфильмы и семейное, до `KIDS_MAX_AGE`+.
- **Место на диске** проверяется перед закачкой (запас `DISK_RESERVE_GB`); не влезает — бот
  подскажет, что удалить. **Зависшие** (`STALL_HOURS` без движения) — предложит другие раздачи.
- **/speed** (админ) — «черепаха» Transmission: 🌙 днём (`DAY_HOURS`), 🛡 пока смотрят, 🛡 при
  перегрузке диска; цифры диска, сети и SMART. Данные даёт агент нагрузки на сервере —
  `sudo sh ~/torrbot/host/install.sh` (ставится вместе со сторожем сервера).
- **Малинка**: скрипты в `pi/` (см. `pi/README.md`) — настройка Kodi и сторож малинки.

## v8: списки, группы, подбор, контроль ИИ

- **/lists** (и /want) — у каждого личный «Хочу посмотреть» и сколько угодно подборок; у группы —
  общий список (👍 — выше) и свои подборки. Под карточкой фильма — «➕ В список» (✅ — уже там).
  В карточке фильма из списка: 👍, ⭐ оценить, ✅ посмотрели, ⬇ раздачи, ➕ в другой список, 🗑 убрать.
  ✅ в личном списке — когда ты оценил фильм или Kodi отметил скачанное тобой; в групповом —
  кнопкой или по Kodi, а личные оценки участников видны как «видели: Лена 8».
- **/gruppy** — группы (семья, друзья): создаёт любой, вступают по ссылке-приглашению
  (новый человек — через заявку админу, с пометкой, кто пригласил). Владелец уходит — группа
  переходит самому давнему участнику. Админ может добавить в свою группу любого пользователя бота.
- **🔗 Поделиться** личным списком — ссылка; получатель видит список только для чтения и может
  забрать фильм себе. Доступ закрывается по одному человеку или всем сразу.
- **⬇ Качать** — новое право в /users (⚙). Без него — «лёгкий режим»: списки, оценки и подбор,
  без раздач, /status и домашнего диска. Все, кто был в боте до v8, право получили сами.
  В заявке на доступ есть кнопка «✅ + ⬇ качать».
- **/sovet** — 🎯 похожее на мои оценки 8+ (рекомендации TMDB, без ИИ), 👥 что посмотреть вместе
  (с пометками «Лена уже видела»), 🤖 подбор по запросу через ИИ.
- **/ai** (админ) — ИИ по функциям (/plot, подбор) и по сервисам, «всем / только отмеченным»
  (⚙ → 🤖 в /users), лимиты в день, расход токенов и ₽ (`AI_PRICE_*`), месячный потолок.

**v8.1:** длинные списки — без кнопки на каждый пункт: пришли номер («5»), короткие — с кнопками.

## v8.2: magnet, инлайн, итоги года, голос, слежение за раздачами, обновление из Telegram

- **📋 Magnet** — у кого нет права «⬇ Качать»: под карточкой найденного фильма кнопка
  «📋 Magnet · 2160p · 45 ГБ · 👤120» — нажал, ссылка скопирована, вставляешь в свой торрент-клиент.
  Берётся лучшая раздача **без фильтров приставки** (4K, HDR, remux можно), «экранки» отсекаются.
  Фильтры поиска (`MAX_HEIGHT`, `BLOCK_*`, размер) — только для закачки на домашний сервер.
- **Инлайн-режим**: в любом чате `@бот название` → варианты → в чат уходит карточка фильма с кнопкой
  «🤖 Открыть в боте». Работает только у пользователей бота. Включить один раз: @BotFather →
  `/setinline` → выбрать бота → подсказка, например «название фильма».
- **/itogi [год]** — итоги года: посмотрено, оценки, скачано, любимые жанры, лучшее за год;
  по группам — общий итог и любимое у группы. 30 декабря в 19:00 — рассылка каждому
  (`ITOGI_DAY`, `ITOGI_HOUR`). Только по базе бота — бесплатно.
- **🎤 Голосовые** — «хочу Интерстеллар» голосом → Yandex SpeechKit → обычный поиск
  (длинное описание сюжета — в /plot). Ключ Алисы, нужна роль `ai.speechkit-stt.user`.
  В /ai — выключатель «🎤 Голосовые» и расход (≈0,16 ₽ за каждые 15 с, `AI_PRICE_STT`);
  дневные лимиты ИИ голос не тратит, месячный потолок — учитывает. До `STT_MAX_SEC` (30) секунд.
- **🔔 Сообщать о раздачах** — кнопка в /lists, у каждого своя, по умолчанию выключена. Раз в
  `LISTWATCH_HOURS` бот проверяет непросмотренные фильмы из твоих списков и списков твоих групп и
  пишет, когда раздача **появилась** или впервые стала хорошей (≥ `WAIT_MIN_HEIGHT`). Что уже было
  при первой проверке — молчит. Кто может качать — кнопка «⬇ Найти раздачи» (уже скачанное
  пропускается), остальным — «📋 Magnet».
- **Обновление из Telegram** (админ) — пришли боту `torrbot-vX.Y.zip` → «✅ Обновить». Программа на
  сервере (`host/update-agent.sh`, ставится `sudo sh ~/torrbot/host/install.sh`) делает `deploy.sh`,
  ждёт, что новый бот поднялся, иначе сама откатывает (`rollback.sh`); при успехе — `git commit` и
  `git push` в ~/torrbot (`UPDATE_GIT_PUSH=0` — не пушить). Итог приходит сообщением прямо с сервера.
  `/update` — состояние и итог последнего обновления; лог — `~/torrbot/data/update/last.log`.

## Обновление и откат версий

```bash
sh ~/torrbot/deploy.sh ~/torrbot-v5.zip     # снимок текущей версии + обновление
sh ~/torrbot/rollback.sh                    # список снимков
sh ~/torrbot/rollback.sh v4-20260929-1900.tar.gz   # вернуть код этой версии
```
Снимки — в `~/torrbot-versions/` (код, `.env` и база бота; закачки не входят).
Откат возвращает только код: `.env` и база остаются текущими — старые версии их понимают.
Версия бота — `/version` (админ) и первая строка лога.

С v8.2 — проще: прислать архив боту в Telegram (см. «v8.2» выше). Программа на сервере
ставится/обновляется так: `sudo sh ~/torrbot/host/install.sh` (после обновлений, где менялась
папка `host/`, — запустить ещё раз).

## Отмена закачки

Кнопка **✖ Отменить закачку** в сообщении «Поставил на закачку» и **✖ N** в `/status`,
с подтверждением. Удаляет торрент вместе с файлами. Пользователь отменяет только свои,
админ — любые (владельцу приходит уведомление).

## Удаление скачанного — /delete

`/delete` (или «🗑 Удалить скачанное…» внизу `/status`) — всё из movies/ и series/, и
скачанное ботом, и положенное руками, большие сверху. Номер → карточка (размер, кто
поставил, смотрели ли в Kodi) → «🗑 Удалить» → «Точно?». У сериала можно удалить отдельный
сезон (папку). Раздачи снимаются в Transmission с файлами, остальное бот удаляет сам;
потом Kodi чистит медиатеку. По умолчанию — только админ; право даётся в `/users`
(кнопка «🗑 удалять»). Удаляет не админ — админу сообщение (`NOTIFY_ADMIN_ON_DELETE=0` — выкл.).

Внизу списка — сортировка **📦 По размеру** / **⭐ По оценке** (худшие по средней оценке сверху,
без оценок — в конце; рядом с каждым — «⭐ 4.5 (2)»). Выбор запоминается для каждого.

## Что смотрели и оценки — /ocenki

Всё, что докачалось через бота, записывается в журнал (одно название — одна запись;
при первом запуске v6.3 туда попадает и всё скачанное раньше).

**У каждого своя оценка** (v6.5). В списке — средняя и сколько оценок: «⭐ 7.5 (3)», и твоя
оценка; в карточке — оценки всех: «Алиса 8 · Боб 7 · Артём — не смотрел(а)».
«Не смотрел(а)» записывается только за тобой и в средней не учитывается.

Кого бот спрашивает «⭐ Как вам …?» (кнопки 1–10 и «Не смотрел(а)»):
- **досмотрели на ТВ** — того, кто ставил закачку (проверка раз в `RATE_WATCH_MINUTES`=30 мин;
  фильм — сразу, сериал — когда досмотрены все скачанные серии);
- **удалили через /delete** — того, кто удалил, и того, кто качал (если это другой человек);
- **автоочистка** — того, кто качал.

Каждого про каждое название автоматически спрашивают один раз. Тот, кто сам нажал «Удалить»
или «Посмотрели на ПК», получает вопрос, если ещё не ответил. Не ответил — не страшно:
неоценённое лежит во вкладке «✍ Мне оценить».

`/ocenki` — вкладки «📅 По дате», «⭐ По средней» (весь список: лучшие сверху, без оценок
внизу), «👤 По моей» (твои лучшие сверху), «✍ Мне оценить (N)»; номер → карточка:
оценки всех, кнопки 1–10 для своей оценки, «Не смотрел(а)», «Сбросить мою». Сбросить можно
только свою оценку. Админ может убрать запись из списка целиком (вместе с оценками; файлы
это не трогает).

Смотрели на ПК, а не на ТВ — кнопка **✅ Посмотрели на ПК** (под «Скачано», в карточках
/delete и /ocenki) отмечает это в Kodi на малинке, и автоочистка работает как обычно.

## Резервные копии и восстановление

| Что | Когда | Где |
|---|---|---|
| База, `.env`, настройки Transmission, `extra/` | каждый день в `BACKUP_HOUR` (4:00), последние `BACKUP_KEEP` (14) | `~/torrbot/data/backups/torrbot-backup-*.tar.gz` |
| То же — файлом в Telegram (копия вне сервера) | еженедельно и по `/backup` | чат с ботом (у админа) |
| Копия базы перед запуском новой версии | при каждом обновлении/откате, последние 5 | `~/torrbot/data/backups/before-v*.sqlite3` |
| Снимок кода, `.env` и базы | при каждом `deploy.sh` | `~/torrbot-versions/` |
| Код | после каждого `git push` | GitHub |

Фильмы на диске в бэкапы не входят. `/backups` (админ) — список копий на сервере.

```bash
sudo sh ~/torrbot/restore.sh                          # список копий
sudo sh ~/torrbot/restore.sh torrbot-backup-20261002-0400.tar.gz          # вернуть базу
sudo sh ~/torrbot/restore.sh ~/torrbot-backup-20261004.tar.gz --full      # + .env и настройки
```
Перед восстановлением текущее состояние сохраняется в `data/backups/before-restore-…/`;
команду отмены скрипт печатает в конце. Старую базу бот при запуске сам обновит под текущую
версию; копию от более новой версии скрипт не восстановит, пока не обновишь бота.

## 5. Семья

Родственник пишет боту `/start` → тебе приходит запрос с кнопками «Разрешить / ✅ + ⬇ качать / Отказать».
С v8 новый человек без права качать пользуется только списками и подбором (право — в /users).
- `/users` (только админ) — пользователи: с какого дня, когда были, сколько закачек и
  сколько занимают на диске; кнопки 🚫 убрать доступ (сможет попросить снова) и ⛔ блок
  (запросы от него больше не приходят). Там же ожидающие запросы и заблокированные.
- Повторный /start, пока запрос ждёт, админа не дёргает; заблокированному бот не отвечает.
- Качает каждый в общую папку, уведомление о готовности получает тот, кто поставил.

## 6. Kodi видит папку сервера

На сервере — общая папка по SMB (только чтение, без пароля — внутри домашней сети):
```bash
sudo apt install -y samba
sudo tee -a /etc/samba/smb.conf >/dev/null <<'EOF'

[media]
   path = /mnt/media
   read only = yes
   guest ok = yes
   browseable = yes
EOF
sudo systemctl restart smbd
```

В Kodi: **Видео → Файлы → Добавить видео → Обзор → Добавить сетевое расположение**
- протокол SMB, сервер `192.168.1.30`, общий ресурс `media/movies` → ОК
- **Тип содержимого: Фильмы**, источник данных TheMovieDB → ОК → «Обновить медиатеку: Да».
- Так же для `media/series` с типом **Сериалы**.

После этого скачанное появляется в разделе «Фильмы» с постерами и описанием.
Новые фильмы подхватываются при обновлении медиатеки (можно включить «Обновлять при запуске»).

## Обновление и удаление

```bash
docker compose up -d --build     # после правки кода или .env
docker compose down              # остановить
```

Удалить просмотренное: через веб-интерфейс Transmission («Удалить с данными») или просто файлы в `/mnt/media`.
В `data/bot.sqlite3` хранится, кто и когда что поставил и когда докачалось, — на этом потом можно сделать автоочистку.

## Развернуть у себя

Всё, что зависит от конкретной сети, — в `.env`. Другому человеку достаточно:
скопировать папку → заполнить `.env` (свой токен, ID, путь к диску, прокси или пусто) → `docker compose up -d --build`.

## Настройки фильтров (.env)

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `MAX_HEIGHT` | 1080 | Максимальное разрешение. Для приставки с 4K — 2160 |
| `BLOCK_CODECS` | hevc,av1,vp9 | Кодеки, которые не показывать. Для мощной приставки — пусто |
| `BLOCK_HDR` | true | Скрывать HDR/Dolby Vision |
| `MAX_SIZE_GB` / `MAX_SIZE_SERIES_GB` | 20 / 80 | Лимит размера фильма / сезона |
| `MIN_SEEDERS` | 2 | Не показывать «мёртвые» раздачи |
| `BLOCK_WORDS` | 10bit,remux,camrip… | Стоп-слова в названии |

Кодек и разрешение бот берёт из анализа файла (ffprobe), который jac.red делает для многих раздач,
а если его нет — из названия раздачи.


## Сторож сервера (вне Docker)

Бот живёт в контейнере, а весь трафик контейнеров идёт через туннель. Если туннель лёг
или бот упал, сам бот об этом не скажет. Поэтому есть отдельный сторож на самом сервере:
`host/host-watch.sh`, запускается systemd-таймером раз в 3 минуты, пишет в Telegram
напрямую (трафик самого сервера идёт мимо туннеля). Токен и ID админов — из `.env`.

    sudo sh ~/torrbot/host/install.sh        # установка / обновление сторожа и агента нагрузки (+ тестовое сообщение)
    sudo torrbot-host-watch --status         # что сторож думает сейчас
    systemctl list-timers torrbot-host-watch.timer
    sudo systemctl disable --now torrbot-host-watch.timer   # выключить

Тревога — после 2 неудачных проверок подряд (~6 мин), «снова работает» — один раз.

## Агент нагрузки (вне Docker, v7)

`host/load-agent.py` — служба `torrbot-load-agent`, ставится тем же `install.sh`. Каждые
5 секунд пишет в `~/torrbot/data/host-load.json`: занятость диска с медиатекой, МБ/с,
отклик, сеть, какие фильмы открыты по Samba и с какого адреса, SMART (раз в 6 ч,
нужен `smartmontools` — install.sh ставит сам). Бот по этим данным тормозит закачки и пишет админу.

    sudo torrbot-load-agent --once           # один замер на экран
    systemctl status torrbot-load-agent      # работает ли
